运行命令（先进入项目根目录）：

```bash
python3 -m unittest discover -s tests -v
python3 -m crashlab doctor
python3 -m crashlab models
python3 -m crashlab --data /tmp/crashlab-demo demo
python3 -m crashlab --data /tmp/crashlab-check check --output /tmp/crashlab-check/report.json
python3 -m scripts.verify_docker
python3 -m scripts.verify_live --task page-slices --data .crashlab-live --output examples/live-check.json
```

`scripts.verify_docker` 会运行真实 Docker 并覆盖 `examples/docker-check.json`，不使用真实模型凭据或推理请求。`elapsed_ms` 为 supervisor 累计的 worker 活跃时间，不含人工等待恢复的时间。`model_calls` 是远端请求尝试；`fixture_calls` 单独记录离线生成，不能混用。未知计费请求不能以零 token 解释。
